# 🚀 Quick Start Guide

## Step 1: Add Your Images

1. Save the **SP Jain logo** (the image you provided) as `images/university-logo.png`
2. Take a screenshot of your dashboard and save it as `images/dashboard-screenshot.png`

## Step 2: Open the Presentation

**Option A: Direct Open (Easiest)**
- Double-click `index.html` to open in your default browser

**Option B: Local Server (Better)**
```bash
cd presentation
python -m http.server 8080
# Open browser to http://localhost:8080
```

## Step 3: Navigate Slides

- **Arrow Keys** → Move between slides
- **F Key** → Fullscreen
- **ESC** → Overview of all slides

## Step 4: Update Subject Code (if needed)

Open `index.html` and find:
```html
<p class="subject">Introduction to Databases</p>
```

Replace with your actual subject name and code.

## 📱 Quick Test Checklist

- [ ] Both images load correctly
- [ ] All 11 slides display properly
- [ ] Text is readable (white on dark)
- [ ] Neon-teal colors show (headings, borders)
- [ ] Navigation works (arrow keys)

## 🎯 Ready to Present!

You're all set. Practice navigating through the slides and time your presentation (aim for 10-15 minutes).

**Pro Tip:** Press `F` for fullscreen mode during presentation!
